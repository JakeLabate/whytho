Every element on a page is a decision somebody made.

WhyTho pins the reasoning to the element itself. Turn it on over any page you can load, select something on desktop or on a phone, and write down why it is that way. The note carries the selector, the breakpoint it was taken at, and who made the call. Everything saves to your account, so the record follows you across machines rather than sitting in one browser.

  1. Load the page you want to document and start WhyTho.

What it does not do

  • It cannot open someone else's site in a frame and annotate it. Most sites refuse to be framed, so WhyTho runs in the page instead. That means you need to be able to load the page yourself.
  • Notes are yours alone. There is no sharing between accounts yet, so a handover happens through a Markdown, CSV, or JSON export.
  • Selectors are recorded as written at the time. If a template changes underneath a note, the pin shows as unresolved rather than silently pointing at the wrong thing.
